# Meeting Recorder 0.2.1

会议报告默认先展示全场总览，再按模板组织进展、结论、行动和未解决问题。已有详细分析可独立提炼，更换模板生成新版本；展开依据继续查看原文和画面。新分析完成后自动提炼，失败可单独重试。支持仅导出纪要或包含详细分析与证据的完整 Markdown。

会议详情新增「删除会议」。确认后移入会议库的「最近删除」，不再进入会议列表、待确认建议与问答检索，可随时恢复。音视频、历史版本和已确认项目记录的依据保留；此功能不永久删除文件、不释放磁盘空间。录制、录像整理和后台任务未结束时禁止删除；备份包含最近删除的数据。

右上角「关于 / About」下拉面板显示实际运行版本，来自 Electron 的应用版本信息。

验证：73 项桌面业务单元测试、17 项转录服务测试通过；19 项 Electron 桌面用例已验证（原有用例全量回归，新用例修正后复验）。构建、TypeScript、Prettier、Ruff 检查通过。删除与恢复使用隔离的合成会议验证，覆盖确认取消、重启、备份恢复、搜索排除、任务保护及项目记录的历史引用。

全场提炼另使用三场现有会议的独立副本完成真实模型验证，正式库未改动，结果与限制见 [全场纪要](../meeting-minutes.md)。模型核对不代表事实准确率保证；重要结论仍需核对依据。此次未进行 Mac 实机验收。
