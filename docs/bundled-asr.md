# Windows 内置转写

0.2.5 的 Windows x64 安装包只包含转写运行程序和 FFmpeg，**模型在安装后按语言下载**。用户不需要安装 Python、CUDA、FFmpeg，也不需要启动独立转录服务。模型只在执行转写时加载，任务完成或取消后退出，释放进程内存。纪要、图像分析和问答继续使用原来的外部 LLM 接口及数据发送授权。

## 使用

1. 录音结束或导入音视频后，在「分说话人转录」旁选择「转写语言」。中文及中英混说使用 Qwen3-ASR 0.6B INT8，英语使用 SenseVoiceSmall INT8。
2. 首次点击转录时自动下载所选语言的模型，任务卡显示下载和转写进度。也可在「设置与备份 → 服务与权限」提前下载中文或英文模型，查看大小、暂停、继续或重试。
3. 点击原文时间戳回听，校对文字与说话人。结果过短的语音片段会提示回听，修改文字后清除提示。

语言也可写入会议背景或项目默认值。转写语言、界面语言、报告语言互相独立；重试保持该任务原先选择的转写语言与关键词，想改变语言须新建转录任务。中文使用已保存的关键词，英语不追加提示词。没有自动语言判断或跨模型补写。

下载需要联网，从清单固定的 Hugging Face、GitHub 公共来源获取文件，不上传录音。支持断点续传；不支持 Range 的服务器会重新下载当前文件。每个文件核对大小和 SHA-256 后才可使用，下载失败或取消不会覆盖原文。下载完成后，本地转写可离线运行。

中文所需文件约 1.02 GB，英文约 276 MB；两者共用约 37 MB 的语音检测和说话人模型，全部下载约 1.26 GB。缓存位于 `%APPDATA%/meeting-recorder/models/asr-v1/`（使用 `MEETING_DATA_DIR` 时改在该目录下），与安装目录及会议库分开。正常升级可继续使用，不重复下载；完整会议备份不包含可重新下载的模型。迁移到新电脑后可重新下载。中断文件保留为 `.partial`，应用重启后再次下载会继续使用。

「设置与备份 → 服务与权限」默认采用内置本地转写。外部转录服务仍可显式选择；历史远程任务继续绑定原任务的方式，任务卡会说明本地或外部。选择外部转录时仍需要原来的数据发送授权，本地转写无需该授权。旧设置中的 LLM 地址、密钥及授权保留。

## 模型与定位

推理由 sherpa-onnx 1.13.8 在 CPU 上运行，固定 4 线程。Silero VAD 找语音片段，Pyannote 分割与 CAM++ 声纹结合已有的整场说话人归并逻辑；未知或重叠声音保留待确认，不计为确定人数。说话人修复仍保留原文、ID、时间和已确认姓名约束，支持人数提示。

中文使用真实语音边界及稳定说话人切换点定位，**不是逐词时间戳**；英文采用模型输出的 CTC token 时间位置。中文短轮次及重叠讲话可能落在同一片段，需人工回听。对比实验的准确率不等于本次完整流水线在所有会议上的准确率，说话人尚无人工 DER 验收结果。

实测资源占用与质量见 [模型对比](lightweight-asr.md)。Qwen3 在实验中有异常短输出案例，因此对明显过短或空的语音识别结果保留核对提示；这只能捕获部分异常，不能自动发现全部漏词。

## 构建与验证

开发/构建机器需要 Node.js 24、Python 3.12 与 Windows x64；用户安装后不需要这些开发环境。

```powershell
npm ci
npm run prepare:local-asr
npm run dev
# 包含资源校验、构建、打包；不发布到远端
npm run dist:win -- --publish never
```

准备脚本使用独立构建环境，下载固定来源与哈希的 FFmpeg 8.1.2，通过 PyInstaller 生成独立转写程序，复制到已忽略的 `.local/bundled/`。构建不下载模型权重。依赖、模型许可及下载清单随安装包分发。清单位于 `shared/asr-models.json`，固定 URL、文件大小和 SHA-256；模型权重和真实会议资料都不进入 Git。打包前核对清单和 worker 源文件哈希，打包后拒绝包含 `.onnx` 或 `models/` 的输出。资源白名单排除旧构建缓存中的模型。Windows 构建复用 npm 安装的同版本 Electron，避免重复解包目录重命名失败。

```powershell
npm test
python -m pytest service -q
$env:MEETING_REAL_ASR_E2E='1'
# 公开测试音频来自对比实验的 Qwen 分发包；构建本身不会下载该包
python scripts/download-asr-candidates.py qwen3
# 复用独立验收目录的模型缓存；不使用正式会议库
$env:MEETING_ASR_E2E_DATA=(Join-Path (Get-Location) '.local/asr-download-e2e')
npx playwright test tests/e2e/local-asr.spec.ts
# 对打包目录执行相同实测
$env:MEETING_PACKAGED_EXE=(Resolve-Path 'release/win-unpacked/Meeting Recorder.exe').Path
npx playwright test tests/e2e/local-asr.spec.ts
```

实际模型桌面测试使用独立会议库和公开样本，不修改安装版会议库；限制子进程 PATH 为 Windows 系统目录，检查设置中下载英文模型、首次转写自动下载中文模型、无外部发送授权时的中英文转写、结果入库、说话人修复以及运行中取消保护。常规 UI 测试默认跳过真实下载与模型检查，需要显式启用。下载器的独立测试覆盖断点续传、忽略 Range 的服务器、损坏文件、取消、跨语言共用模型和重启后的离线使用。Mac 的内置运行程序尚未打包，默认继续使用外部转录方式。

## 本机交付记录

0.2.4 本机试用包曾包含全部模型，安装包约 1.22 GB。0.2.5 改为安装后下载，本机安装包约 189 MB，减少约 84%；正式版本由 `v0.2.5` 标签流水线生成。

0.2.4 已验证两种模式对 10 秒纯静音均返回 0 段文本。0.2.5 的模型和推理逻辑沿用该版本，增加下载与缓存测试。PATH 限制验证了独立运行能力；尚未在全新 Windows 虚拟机或所有 CPU 型号上验收。
